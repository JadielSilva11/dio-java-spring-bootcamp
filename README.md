# Java Springboot with Artificial Intelligence Learning Path

Este repositório reúne meu processo de aprendizado na linguagem **Java** e no ecossistema de desenvolvimento de software, abrangendo desde os fundamentos da programação orientada a objetos até a construção de aplicações Back-End com Spring Boot e a exploração de soluções baseadas em Inteligência Artificial.

O objetivo é consolidar conhecimentos em desenvolvimento de software, compreender os principais conceitos da linguagem Java e aplicar boas práticas de arquitetura, integração de sistemas e desenvolvimento de APIs REST em projetos práticos.
